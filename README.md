# Digital Complaint Box System

A secure web-based complaint management platform designed for colleges and institutions to simplify complaint submission, tracking, and resolution.

## Features

* Student login and dashboard
* Submit complaints online
* Identity protection for complainants
* Complaint tracking system
* Admin management panel
* Complaint status updates
* Clean and responsive user interface

## Technologies Used

* HTML
* CSS
* JavaScript
* Firebase Authentication
* Firebase Firestore
* Firebase Hosting

## Purpose

To digitize complaint handling, improve transparency, and make issue reporting easier for students and institutions.
